## Project Description

A full-stack data analytics and machine learning system that benchmarks three fundamental
computer-science algorithms — **Iterative Binary Exponentiation**, **Dynamic Array
Reallocation** (`std::vector`), and **Linked List Deep Traversal** — across input sizes
ranging from N = 10 to N = 5,000,000.

The system instruments sub-microsecond execution timing and byte-accurate heap allocation
tracking at the C++ level, feeds that telemetry into a Python ML pipeline, and surfaces
real-time predictions and cloud cost risk analysis through an interactive Streamlit dashboard.

### Business Value

| Pain Point | Solution |
|---|---|
| Over-provisioned cloud VMs | ML model predicts exact memory footprint before deployment |
| Unpredictable execution spikes | Rolling-median cleaned telemetry + anomaly indicator |
| No algorithm-selection guidance | Cloud Cost Risk Threshold chart identifies the N at which cost escalates 10× |
| Manual reporting | `generate_report.py` auto-generates a formatted Word document |

## Dataset Description & Schema

Generated by `telemetry_gen.cpp` — a C++17 binary with overloaded `operator new/delete`
for byte-accurate heap tracking and `std::chrono::high_resolution_clock` for µs timing.

| Column | Type | Description |
|---|---|---|
| `algorithm` | string | `binary_exponentiation` · `vector_reallocation` · `linked_list_traversal` |
| `input_size` | int64 | Problem size N (geometric steps ×1.5 from 10 to 1,000,000) |
| `execution_time_us` | float64 | Wall-clock time in **microseconds** |
| `memory_bytes` | float64 | Cumulative heap bytes allocated during the benchmark window |

## Installation & Run Instructions

### 1. Clone / enter the project directory

```bash
cd /home/sahil/collage/os/project
```

### 2. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 3. Generate telemetry data (C++ benchmark)

```bash
g++ -O3 -std=c++17 -o telemetry_gen telemetry_gen.cpp && ./telemetry_gen > telemetry_raw.csv
```

### 4. Train the ML models

```bash
python ml_pipeline.py
```

### 5. Run the Jupyter notebook (full analysis)

```bash
jupyter notebook SahilRashidKachroo_AlgorithmicResourceAnalytics.ipynb
```

### 6. Launch the Streamlit dashboard

```bash
streamlit run app.py
```

Open your browser at **http://localhost:8501**

### 7. Generate the Word report

```bash
python generate_report.py
```

Outputs `SahilRashidKachroo_ProjectReport.docx` in the project directory.

### 8. Generate the static dashboard image

```bash
python dashboard.py
```

Outputs `cloud_compute_dashboard.png`.
